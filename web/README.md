# stockiq Web Frontend Foundation

This directory is designated for the web-based frontends:
1. **Investor-Facing Portal**: Discovery, subscription checkout, research consumption, and portfolio tracking.
2. **Provider Suite (RA/IA)**: Research publication, recommendation management, performance verification tracking, and client agreement administration.
3. **Admin & Compliance Console**: SEBI verification workflows, content moderation, complaint resolution, and audit inspection.

*Note: Per Phase 1 Foundation specifications, frontend UI implementations are scheduled for subsequent phases.*
